ECG Verification project page

The website is in docs/. It uses static HTML, CSS, and JavaScript.
The interactive demo uses synthetic signals. The desktop screenshot is
docs/figs/sample.png. The deployment uploads docs/ only, including this image,
not the sample/ or processed/ data directories.

LOCAL PREVIEW
From ECG_Verification:
  ecg/bin/python -m http.server 8080 --directory docs
Open http://localhost:8080 in your browser. Stop with Ctrl+C.
You can also open docs/index.html directly.

PUBLISH ON GITHUB PAGES
The repository root must contain docs/ and .github/workflows/pages.yml.
Upload or commit these paths at the root of the ECG Verification repository.
In GitHub, open Settings > Pages > Build and deployment and select GitHub Actions.
Push to main/master, or open Actions > Publish project page > Run workflow.
The completed deployment reports the website URL.
For a project repository, the URL is https://OWNER.github.io/REPOSITORY/.

This project has its own Git repository linked to
https://github.com/UARK-AICV/ECG_Verification.git.
The published page URL is https://uark-aicv.github.io/ECG_Verification/.

The page presents the project objective and workflow: PQRST segmentation,
clinical-rule-guided candidate localization, and clinician annotation refinement.
The browser preview demonstrates lead selection, visibility, and measurement;
annotation editing is performed in the desktop application.
